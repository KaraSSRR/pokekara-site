01Meet the developer

Anatolii Ushakov leads Pokekara Studio from Ukraine. The studio is presently an independent development initiative, not a separately incorporated legal entity. The name is a project and studio identity, not a claim to an American LLC or other registered company.

Anatolii defines the game vision, chooses development priorities, evaluates technical evidence and makes final design and release decisions. Claude Code plays a substantial role in design and implementation within that founder-directed process.

02VITALE: Football Career

VITALE follows an individual footballer through development, selection, matches, contracts, transfers and the consequences of a career that unfolds inside a persistent football world.

The project prioritizes simulation and player agency. Match outcomes, footballer states and long-term world progression are engineered in C# systems, while the planned Unity mobile presentation and Blender character pipeline are separate development workstreams.

03What exists today

VITALE is more than an idea-stage presentation. The underlying RTL engineering project includes implemented systems and automated validation. Work reported here is development evidence, not proof of a commercially released mobile build.

Deterministic MatchEngine

Match simulation and regression testing are designed to produce reproducible results from the same inputs and simulation version.

Persistent WorldEngine

Clubs, competitions and player careers evolve over simulated time; save/reload/resume behavior is validated in engineering tests.

Player lifecycle

Development, fatigue, recovery, form, injury and career evolution are modeled as persistent simulation state.

Transfer-market engineering

Contracts, transfers, loans and club autonomy are implemented. Wage-policy calibration and longer-horizon economic acceptance are still in progress.

Automated verification

C# test suites, architecture guards, deterministic comparisons and release builds are used to check regressions before integration.

Character pipeline

Blender and game-asset workflows are in active development. Human facial anatomy, deformation quality and final visual acceptance are not yet production-approved.

Evidence, not invented traction

We do not claim users, downloads, funding, revenue, store availability, or a finished playable release that does not exist. Detailed development logs, private source history and QA artifacts can be discussed through an appropriate verification process.

04Claude is central to the workflow

Claude Code is a primary tool for the project's gameplay-system design, software architecture, C# implementation, code review, deterministic QA and creative/technical development. It also supports character-production planning and Blender-related workflows. Visual quality is reviewed separately and remains under development.

The engineering loop is explicit: product direction → architecture → implementation → tests → independent review → developer acceptance. Claude contributes across the design and technical stages; Anatolii retains decision-making authority.

05Current development status

Active pre-release development. The simulation core has significant implemented and tested functionality. Market economics, visual character quality, broader integration and the mobile client continue through engineering and acceptance work.

The interface shown on our homepage is a representative concept, not footage from a finished game. VITALE is planned for iOS and Android. No public release date has been announced.
