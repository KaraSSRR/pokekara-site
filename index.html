A deliberate choice

VITALE does not chase a giant open-world 3D environment. We put our resources into simulation depth, persistent world state, meaningful career decisions, mobile UX and a selection of high-impact 3D moments — the parts that make a career feel real.

Technology

Built as a Simulation Platform, Not a Collection of Screens

Underneath the interface, VITALE runs on connected systems that keep the football world consistent from one week, season and career to the next.

Experience

Mobile career interface

Portrait-first, one-thumb screens and selected 3D moments.

Simulation

MatchEngine

Headless, deterministic match simulation — the same inputs give the same result.

Competition Engine

Leagues, scheduling and competition execution across the season.

Transfer Systems

Market architecture for interest, moves and contracts.

World state

WorldEngine

The persistent football world that keeps moving between sessions.

Persistent Player State

Identity, roster data and history for every footballer.

Player Lifecycle

Development, aging, fatigue, injuries and physical profile.

Foundation

Data Pipeline

Structured, validated data feeding players, clubs and competitions.

QA / Deterministic Validation

Automated tests and reproducible simulation checks run across every layer.

Separating simulation from presentation means the football world can be tested, balanced and extended independently of any single screen.
